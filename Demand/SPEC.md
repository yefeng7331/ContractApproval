# 合同审批智能审查系统：首阶段可执行 SPEC

状态：待用户验收；本文是首阶段产品与验收约定，尚不代表功能已实现。  
需求来源：[Demand.md](Demand.md)。适用范围：中国大陆法域的软件采购合同演示。  
本阶段仅确定 SPEC；核心流程设计、技术选型、代码和真实审批平台集成在后续阶段处理。

## 1. 目标与交付边界

交付一个可运行的本地演示系统：业务经办人通过本地上传或模拟审批待办提交合成软件采购合同；系统解析 DOCX、PDF、扫描件，生成可追溯的条款与风险草稿；法务核对、修改并确认；系统生成 Markdown/PDF 报告，并将确认后的意见写入**模拟审批评论区**。大盘与双栏工作台可展示该链路，本地测试账号在服务端实施三角色权限。

首阶段验收必须说明“模拟回写成功”，不得描述为已接入真实企业审批系统。风险规则是可审的演示规则；未获法务确认的法律解释不得作为已验证的法律合规结论。

### 范围标记

- **一期**：本 SPEC 定义的可运行演示及固定样例验收。
- **后续**：原需求保留，但不计入一期通过条件。
- **待决**：需法务或真实系统资料才能锁定，不能由实现者猜测。

## 2. 角色、可见性与页面

| 角色 | 一期可执行操作 | 权限边界 |
| --- | --- | --- |
| 业务经办人 | 用本地测试账号登录；上传合同；查看本人任务状态；在法务确认后查看风险、整改建议并下载报告 | 法务确认前只能看到任务进度及阻塞原因，不得通过页面、接口或下载获取风险草稿与报告；不能复核或回写 |
| 法务审查人 | 查看待复核合同与原文证据；编辑风险等级、建议和批注；确认审查结论；触发模拟回写；下载已确认报告 | 未确认不得回写；每次确认须记录账号、时间与审查版本 |
| 系统管理员 | 查看任务状态与阻塞原因；触发重试或引导重新上传；查看模拟回写结果 | 一期不能代替法务确认、修改结论或触发回写；规则编辑和真实连接参数配置后置 |

本地测试账号只是演示身份机制，账号之间必须由服务端隔离权限，不能仅靠前端隐藏按钮。企业单点登录与真实组织权限映射后置。

一期页面：大盘展示合同名称、申请人、业务类型、合同金额、任务状态、综合风险等级、创建时间、状态/风险筛选与手动上传；未确认结论对业务经办人隐藏。工作台左侧展示分页原文、元数据与风险高亮，右侧展示风险卡片、依据、差异和可编辑建议；点击任一侧的定位目标，另一侧同步选中并跳页。法务区展示摘要、批注、确认、模拟回写状态和报告预览。批量操作、规则配置页及模板编辑页后置。

## 3. 一期输入、输出与数据契约

### 3.1 输入与解析

- 输入 A：业务经办人本地上传 DOCX、含文本层 PDF 或图片扫描件；输入 B：从模拟审批待办取得合成附件与申请信息。两种入口产生相同的审查任务结构。真实事件监听、拉取、下载与去重后置。
- 每份附件保存来源、格式、内容摘要、版本、提交人和提交时间。重新上传产生新文档版本，不覆盖旧版审查与回写记录。
- 解析结果至少包含合同标题/编号、送审部门/申请人、双方主体及统一社会信用代码、金额/币种、履行期限、生效条件；无法提取的字段标记“未识别”，不得补造。
- 输出按原文顺序的段落树和条款类型，包括标的、付款、验收、违约、保密、数据安全、知识产权、争议解决。未出现的条款标记“未找到”，不生成虚构原文。
- 原文锚点含文档版本、原文片段、起止字符位置、页码及段落索引。字符位置采用规范化全文的 Unicode 字符序号，零起始、终点不含；页码为预览版本的一起始页码，段落索引零起始。DOCX 页码以本次生成的固定预览版本为准。OCR 的坐标与识别文本对应同一版本。界面定位必须命中该锚点；无法可靠定位的发现不可显示为“已精准定位”。

### 3.2 风险与建议

每个风险项至少包含：规则 ID/版本、条款类型、风险类型（企业商业规则或经核准的法律规则）、高/中/低等级、命中原因、原文锚点、依据来源、模型建议、法务最终意见及版本。规则匹配与大模型判断应分别记录；模型输出不能替代原文证据或法务判断。

一期预置两条软件采购演示规则，均标为**企业商业风险**：

| 规则 | 固定样例中的触发条件 | 预期草稿 | 建议方向 |
| --- | --- | --- | --- |
| DEMO-IP-01 | 采购方需要取得或持续使用交付软件，而合同约定相关知识产权全部归供应商，且未给采购方满足项目目的的权利安排 | 高风险；引用权属/许可条款原文 | 提请法务协商权属、许可范围、源代码交付及第三方权利保证；不预设采购方必须取得全部著作权 |
| DEMO-PAY-01 | 合同要求到货即付全款，且付款前没有可执行的验收条件 | 高风险；引用付款条款，并标明验收条款缺失 | 提议按可核验的交付和验收里程碑付款，由法务确定具体金额与比例 |

综合风险等级取法务保留的最高等级；未命中已启用规则时显示“未发现已启用规则风险”，不得显示为“法律安全”或自动归为低风险。解析受阻时不计算综合等级。机器可给出“通过/整改/建议拒绝”的建议，正式结论由法务确认；固定双高风险样例的机器建议为“建议拒绝并整改”，法务可修改且须留痕。界面支持高/中/低风险展示，但其他风险维度和具体中风险阈值不属于一期自动判定范围。

模型必须基于命中条款、规则与批准的示范条款生成建议；输出缺少原文证据、依据或无法生成时，展示原因并转人工处理，不编造法条、统一比例或确定性结论。需求中“双方各承担 50%”“违约金不超过合同总额的 20%”仅是待审示例，不作为系统默认建议或法定阈值。

### 3.3 状态与版本

| 维度 | 值及含义 | 关键转移 |
| --- | --- | --- |
| 机器审查状态 | pending 待处理；parsing 解析中；reviewing 规则/模型审查中；blocked 受阻；completed 机器草稿完成 | pending → parsing → reviewing → completed；任一处理阶段失败 → blocked；重试回到 parsing 或 reviewing，并记录次数、原因 |
| 法务复核状态 | pending 待复核；in_review 复核中；confirmed 已确认 | 机器 completed 后为 pending；法务打开并编辑为 in_review；确认后为 confirmed。修改已确认内容须生成新的审查版本并重新确认 |
| 回写状态 | not_written 未回写；writing 回写中；success 成功；failed 失败 | 仅已确认版本可从 not_written/failed 进入 writing；模拟评论保存成功才为 success；失败保留错误与重试入口 |

机器 completed 仅代表草稿形成，不代表法务已通过。加密、正文为空、严重模糊且无法建立可靠证据、解析失败或审查依赖超时进入 blocked，展示可操作的原因。重新上传从新文档版本开始；仅暂时性失败可按原版本重试。告警一期表现为大盘状态提示，外部通知后置。

模拟回写接收经法务确认的审查版本、格式化 Markdown 评论及目标模拟审批单 ID，返回评论 ID、写入时间和结果。评论包含风险总评、重点事项、法务批注及“演示系统模拟回写”标识。以“任务 ID + 已确认审查版本 + 目标审批单 ID”为幂等键；重复点击或失败重试不得产生第二条同版评论。新的已确认版本回写状态重新从 not_written 开始，可产生新评论，须显式标识版本。

### 3.4 报告

法务确认后，同一审查版本导出 Markdown 与 PDF，包含合同基本信息、综合风险及最终结论、逐项风险等级/原文页段定位/成因/依据/最终修改条款、法务批注、确认人与时间、版本及模拟回写标识。业务经办人仅能下载本人任务的已确认版本。对尚未核准的法律依据显示“待法务核定”，不得输出为正式法律结论。

## 4. 法律依据与待决门槛

规则来源须记录来源类型、标题、条款/版本、生效或核查日期、链接、适用条件和法务确认人。企业商业规则要标明是企业审查偏好，不能写成法律禁止；法律规则只有在适用条件及现行文本经法务确认后才可启用为法律合规判断。

候选核对材料：[《中华人民共和国著作权法》（2020 年修正）第十九条，全国人大法律文本](https://wb.flk.npc.gov.cn/flfg/PDF/3d00c03d87cf4863878081a3e1b54638.pdf)涉及委托创作作品的权属约定；它不支持仅凭“供应商保留权利”就判定合同违法。[《中华人民共和国民法典》第四百九十六、四百九十七条，中央网信办刊载文本](https://www.cac.gov.cn/2020-06/01/c_15925617772683192.htm)涉及格式条款的条件与效力，不能直接套用于所有不对等条款。以上仅为候选法源；是否适用于具体软件采购合同，仍由法务核定。

真实主体经营异常核验的数据来源可参考[国家企业信用信息公示系统](https://bt.gsxt.gov.cn/)；一期不连接该系统，只能使用明确标注的合成状态。真实审批平台接口、回写权限与凭证、企业审查清单及风险阈值、法务签批后的标准条款均为后续或待决资料。

## 5. 固定样例与验收

合成样例不得包含真实企业合同或凭证。建立有标注答案的固定样例集：

| 样例 | 内容与用途 | 必须通过的检查 |
| --- | --- | --- |
| F1 DOCX | 软件采购合同，包含 DEMO-IP-01 与 DEMO-PAY-01 | 核心元数据、两项高风险、条款原文及锚点、法务编辑与模拟回写 |
| F2 文本 PDF | 与 F1 同语义，排版分页不同 | 风险结果一致，页码和高亮落在本版原文 |
| F3 清晰扫描件 | 与 F1 同语义的合成扫描件 | OCR、条款和锚点可人工核对且结果一致 |
| F4 已整改合同 | 明确采购方必要使用权与验收后分期付款 | 上述两条规则不误报；无其他规则命中时显示“未发现已启用规则风险”，不自动宣称“合法” |
| F5 异常附件 | 加密 PDF、正文为空、严重模糊扫描件各一份 | 分别进入 blocked，给出对应原因，不生成虚假结论，可重新上传 |
| F6 模拟接口故障 | 模拟待办附件超时、首次回写失败、重复提交 | 任务或回写状态正确；可重试；同版评论最多一条 |

所有固定样例都须有预期字段、条款、页码、段落、字符位置、风险项与等级的标注清单；一期验收逐项全通过，不以“总体看起来正确”代替。规则/模型固定样例验证可使用受控模型版本与输入，但必须另做一次真实模型调用的 F1 全链路演示；录制或桩响应仅证明测试链路，不能证明模型能力。

| 验收编号 | 可观察结果 |
| --- | --- |
| A1 接入解析 | F1–F3 经上传成功；模拟待办可导入 F1；元数据与主要条款逐项匹配标注 |
| A2 定位联动 | F1–F3 每个预期风险的页码、段落和字符位置匹配本版标注；原文与卡片双向点击准确跳转 |
| A3 风险建议 | F1–F3 命中两条高风险及其依据；F4 不误报；建议可由法务编辑并保留机器/人工版本 |
| A4 复核权限 | 业务账号在确认前无法从页面、接口或下载得到草稿；法务可确认；管理员不能代确认或回写 |
| A5 结论报告 | 法务确认后，业务可查看最终风险；Markdown/PDF 内容与确认版本一致，可下载 |
| A6 模拟回写 | 确认前拒绝；确认后成功写入模拟评论并记录 ID；重复点击/重试不重复；失败显示 failed 与原因 |
| A7 受阻重试 | F5/F6 显示具体阻塞原因；更换文件或重试后状态按新记录推进，不覆盖旧证据 |
| A8 端到端 | 使用 F1 完成模拟待办/上传、解析、审查、法务复核、模拟回写和报告导出，保留演示记录 |

## 7. 一期通过与未决事项

只有 A1–A8 全部通过、固定样例标注可复查，且模拟与真实能力在界面、报告和验收记录中清楚区分，才能判定一期技术验收通过。法务对演示规则和示范条款的确认单独记录；技术通过不替代法务确认，也不授权进入下一阶段。

未决事项：具体企业审查清单与最终阈值；候选法律依据的适用性及法务签批；真实审批平台、接口与身份系统资料；真实经营异常查询权限；生产数据保护和部署要求。这些项目不阻断一期合成数据演示，但不得在未解决前宣称真实集成或正式法律审查能力。
